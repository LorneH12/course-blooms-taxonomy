# Bloom’s Taxonomy: Design Practice That Proves Learning

Independent TurboTax-inspired portfolio sample by Lorne Hopkins. Original twelve-screen design plus SCORM 1.2 and local-lab xAPI adapters.

Open index.html to preview without telemetry. In an LMS, score, bookmark and compact completion state are saved; draft text is excluded. On resume, diagnostic/practice and writing activities must be revisited. A browser API test is not a real Moodle test. See qa/ for executed evidence.

The design baseline in docs predates tracking; current tracking behavior is in js/tracking.js. This is a custom player, not an Adapt export. Production identity, real Moodle import, full accessibility and pilot evaluation remain open.
